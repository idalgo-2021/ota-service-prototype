# SearchMap

Интерактивная карта на OpenLayers.

- Координаты: `[широта, долгота]`, включая вершины полигонов (не порядок GeoJSON).
- `hotels`: маркеры с ценой за ночь; если `price` не задан, на маркере название отеля.
- `points`: начальные пользовательские точки; можно добавлять и удалять в интерфейсе.
  Поле `kind` (`music`, `office`, `station`) задаёт цвет и значок маркера.
- Поиск на карте сначала ищет по названиям точек и отелей на карте, затем — место или адрес через Nominatim (OpenStreetMap, `geocode.ts`), с приоритетом области вокруг города.
  Найденное место показывается маркером, из карточки его можно добавить в «мои места».
  Nominatim бесплатный, но с лимитом 1 запрос/сек.
- Во время ввода под полем поиска появляются подсказки: совпадения среди точек и отелей на карте
  и места из Photon (komoot, тоже данные OpenStreetMap).
  Nominatim для этого не подходит: его правила запрещают автодополнение. Photon бесплатный, без ключа,
  но публичный сервер просит не нагружать его сильно; для прода стоит поднять свой инстанс.
- Районы и города в подсказках помечены «район». При выборе их граница загружается из Nominatim
  (`fetchBoundary` в `geocode.ts`, один запрос на выбор), район добавляется на карту выделенным,
  и карта подгоняется под него. Его можно выключать, как остальные районы, а крестиком в легенде — убрать.
  Если у района несколько частей, показывается самая большая.
- Карту можно развернуть; Escape возвращает обычный размер. Нажатие на место в легенде приближает его на карте.
- `districts`: полигоны районов; первый контур — внешняя граница, остальные — отверстия.
- `selectedDistrictIds`: начальное выделение районов.
- Состояние выбора хранится локально. Колбэки позволяют сохранять его в приложении; для нового поиска нужно поменять `key`, чтобы сбросить выбор.
- Центр и отображаемые отели/полигоны обновляются при изменении `data`.

Подложка — векторные тайлы OpenFreeMap (данные OpenStreetMap) в стиле Bright, без API-ключа;
нужен доступ к интернету. Надписи рисует сама OpenLayers, поэтому их плотностью можно управлять:
настройки в `MapCanvas/basemap.ts` — размер шрифта (`TEXT_SCALE`), зазор между надписями
(`TEXT_PADDING`, чем больше, тем меньше надписей), с какого зума показывать слои (`LAYER_MIN_ZOOM`)
и какие слои скрыть (`HIDDEN_LAYERS`).
Колесо мыши и жест увеличения двумя пальцами над картой меняют масштаб карты.
